# G5b original full-body GPU evidence intake boundary

12 October 2026. Independent first-party Chat Lane G diagnostic only. The intake gate checks whether a proposed review package reports the expected private ORIGINAL_v1 SHA-256, 17,946 vertices, 67 skin joints, an original full-body WebGL2 capture artifact hash and an owner review decision. A passed device capability, palette texture upload, or mock shader-link test **cannot** satisfy these source/capture claims.

Crucially, a JSON object can claim any SHA, capture or approval flag. Therefore the function **never grants approval, production readiness, or independent authentication**, even if all fields are syntactically complete. It marks the fields as complete for subsequent independent artifact verification. No original assets are loaded, no private media is distributed and Work's Blender model/feet/biomechanics are untouched.

Five Node unit tests verify absent evidence, spoofed compatibility-as-capture, substitution/geometry mismatch, pending owner review and explicit failure to self-authorize. Current engine body-render acceptance still requires verified actual browser GPU capture plus human visual and anatomical review. This does not yet provide those proofs.
