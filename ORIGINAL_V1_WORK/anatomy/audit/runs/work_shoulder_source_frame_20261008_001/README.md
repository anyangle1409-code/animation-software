# CP1a shoulder source semantics and thorax frame checkpoint

The previous relative vector mixed Hoogervorst2018 medial/lateral extrema length with Matsumura2020 ventral/dorsal extrema angles and treated pooled means as male context. Its numbers are retained as historical illustrative arithmetic; the vector and feasible-family records are reopened and ineligible for numerical freezing. The male standing means are now source-registered with explicit endpoints, centroid definitions, population and thorax axes. Primary Methods and Tables 1/2 were reviewed at https://link.springer.com/article/10.1186/s13018-020-01934-w and https://d-nb.info/1220757004/34; the length protocol was checked at https://link.springer.com/article/10.1007/s00402-018-2912-2 .

thorax_source_frame.py constructs the source point-mapping frame from caller-provided IJ/C7/PX/T8 landmarks. Analytic basis, signed position, tilted/translated/scaled covariance and malformed/improper-frame regressions pass. Four pre-implementation failures are retained. A synthetic Blender 5.2.1 LTS fixture saves/reloads two mapped points and the frame: errors 2.03e-8 m and 3.58e-8 per frame component, positive determinant. Its first run encountered a NumPy boolean JSON serialization error after geometry capture; the fixture now emits a native boolean and was rerun to a new immutable output. This was a fixture serialization issue, not anatomical evidence.

25 focused tests pass. Full discovery: 796 tests, the same named five failures/four errors as the CP2 checkpoint. Target-selection/atlas validators pass only their existing static scopes. freeze_ready=false. No clinical Euler-angle transformation, source-to-articular offset, global target or population correlation model is inferred from this point-mapping helper.

Essential blockers: endpoint-compatible clavicle length/pose mapping, bilateral SC articular geometry, final canonical thorax landmarks/pose, stature context and independent matched corroboration. Safest next action is a source-compatible surface-to-articular landmark solve while other regional evidence work continues. No new canonical skeleton or production change is made here.
