# G5f — local ORIGINAL_v1 viewer module graph acceptance

An HTTP integration test starts the actual G5e loopback server, fetches the G5c/G5d five-camera owner review HTML, follows its boot module and recursively crawls first-party static `import` / `export ... from` links via the actual server. Requires each source file to return HTTP 200 and a JavaScript content type, no remote or bare module specifiers, and no dynamic import. This catches missing files, unsupported server paths and broken boot-module ancestry before authenticating the private GLB.

It is an ordinary real Node HTTP server test, not a mocked WebGL2 device, and no private assets are needed or transmitted. It does NOT establish JS shader compilation, actual human GPU image, iPhone accessibility (the server is intentionally 127.0.0.1 laptop-only), deforming anatomical motion, feet correction, or production readiness. The test must be updated if legitimate first-party dynamic module loading is deliberately introduced.

Branch remains isolated and draft pending CI. No model, skeleton, PT App or third-party dependencies changed.
