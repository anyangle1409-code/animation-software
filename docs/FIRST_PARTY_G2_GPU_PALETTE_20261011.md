# Lane G2 — first-party WebGL2 four-influence GPU bone-palette skinning

**11 October 2026 · stacked diagnostic GPU parity and controlled original geometry only · no anatomical or production character approval**

This independent software development is stacked on [G1c UV0 PR #53](https://github.com/anyangle1409-code/animation-software/pull/53) and previously verified first-party GLB/source materials/rig binding/CPU skin/GPU triangles, but it does not touch Work's private CT, anatomical candidate, Blender, original human surface or accepted skeleton decisions.

## Implemented

- `src/viewer/firstPartyGpuPaletteSkinning.mjs`: direct first-party **WebGL2 GPU skeletal vertex skinning** using original GLSL 300 es shaders. Keeps source project-approved *engineering* CPU vertex skin reference separate. A small CPU preparation computes **one world-pose × inverse-bind matrix per bone** (no CPU per-vertex deformation). The matrices are uploaded as a single **RGBA32F texel buffer texture**, with **four adjacent RGBA texels per column-major 4×4 joint matrix**. The vertex shader uses `texelFetch` to retrieve correct bone transforms, reads exact uint16 4-tuple `JOINTS_0` via `vertexAttribIPointer`, and weights 4 source matrix×rest-position contributions with exact `WEIGHTS_0`. Perspective view and source UV0 diagnostic fragment use original project shaders with one shared depth buffer, multiple mesh parts, uniform texture UV0 pipeline and strict resource lifecycle.
- All geometry/skin weights, palette lengths, affine proper rigid poses, reflection/shear/scale, UV0 bounds and GPU `MAX_TEXTURE_SIZE` are checked before any framebuffer clear/draw. Source original GLB rig identity-to-world-bind numerical verification is still enforced separately upstream via [PR #46](https://github.com/anyangle1409-code/animation-software/pull/46); this shader does not infer bone side from suffix or alter canonical coordinates.
- **True original GPU↔CPU parity gate**, not just an attractive screenshot: WebGL2 `transformFeedbackVaryings` captures the vertex shader's actual `vSkinnedWorld` 3-vector for each **indexed triangle**; GPU readback `getBufferSubData` is compared numerically against the independent original `deformIndexedSkin` reference at each frame and skin influence. A second synthetic 4-joint/4-nonzero-weight rig verifies all four channels contribute. Diagnostic readback is capped at 8,192 indexed vertices to avoid unbounded GPU resource requests; it is a test aid, not a real-time runtime API.
- `tests/firstPartyGpuPaletteSkinning.test.mjs`: pure Node/zero-npm malformed posed joint, source rig weight, affine/laterality, texture-palette, 4-joint and GPU context-loss tests plus all inherited first-party GLB/UV0/CPU skin GPU tests.
- `scripts/verify-first-party-gpu-palette-browser.mjs`: real Chromium WebGL2 GLB→explicit source joint mapping→vertex-shader GPU skin transform feedback→CPU parity; 20 rendered frames × two source-author-created skinned triangles, UV0 fragment GPU red/green dual framebuffer readback, and four-nonzero joint weighted triangle parity, with numeric tolerance **<1e-5 model units** as a software implementation threshold (NOT anatomical measurement uncertainty).
- `.github/workflows/first_party_gpu_joint_palette.yml`: all original and inherited zero-package Node suites, unchanged editor TypeScript/production build, actual Chromium GPU vertex-shader transform-feedback versus trusted independent CPU result, and no-Three/React module source/browser requests.
