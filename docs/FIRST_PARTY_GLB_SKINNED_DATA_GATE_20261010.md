# First-party GLB2 embedded skinned geometry — strict limited parser

**10 October 2026 — data loader proof only; no patient model, full original human mesh, third-party imported character, or production release.**

## New independent capability

- `src/viewer/firstPartyGlbSkinnedGeometry.mjs` reads raw **glTF 2.0 GLB binary container bytes** directly with browser/Node's built-in `ArrayBuffer`, `DataView` and `TextDecoder`, **without `three`, glTF loader packages, a model marketplace or any npm dependency**. It returns typed mesh data for the preceding [native WebGL2 index/skin renderer in PR #42](https://github.com/anyangle1409-code/animation-software/pull/42).
- Current narrowly specified supported subset: exactly one embedded BIN buffer, one mesh and one TRIANGLES primitive, one skin with 1–128 uniquely named bones, explicit `POSITION` float32 VEC3, `JOINTS_0` unsigned 8/16 VEC4, `WEIGHTS_0` float32 or normalized integer VEC4, indexed triangles with unsigned 8/16/32 indices, inverse bind matrices float32 MAT4 and optional source normals. Reads contiguous or legally strided/interleaved bufferViews with component alignment and per-field bounds. All geometry and skin weights pass the independently tested reference CPU LBS validation. The resulting skin joint node names remain **labels**, never silently mapped to accepted canonical bone identities.
- Fail-closed security and correctness: GLB magic/version/declared file size; chunk alignment; UTF-8 JSON; no external or data: buffer URI, code, images, textures, materials, animations or cameras; no unknown required/used extensions, compression, sparse accessor, morph targets, second weight/joint set, unindexed primitives, extra scenes/meshes/skins, misplaced or nested mesh node, nonidentity mesh-root transform, duplicate/unnamed joint nodes, malformed strides, weights, normal counts, out-of-bounds indices, invalid binary memory ranges, nonfinite positions/skin values or oversized data. Current GLB cap 32 MiB, geometry cap 250,000 vertices, skin palette up to 128.
- Not a compliant *general-purpose glTF implementation* or GLB renderer for arbitrary files. Complex ORIGINAL_v1 GLB imports that exceed this subset must be handled by explicitly expanding the original loader with new acceptance tests, NOT by accepting silently or importing third-party loaders.
- `tests/support/buildSyntheticFirstPartyGlb.mjs` constructs a **wholly original deterministic two-bone triangle model in actual GLB container format**, including skin palette, inverse binds, position data, indices and weights. This is a *test fixture*, never a production human mesh. It has no outside source-license or patient data.
- `tests/firstPartyGlbSkinnedGeometry.test.mjs` verifies exact decoded geometry and actual four-weight skin transform, malformed source bytes/chunks/indices/attributes, source asset/extension refusal and strict no-canonical-provenance approvals.
- `scripts/verify-first-party-glb-browser.mjs` drives a real Chromium browser from the isolated existing native skinning-preview page, imports and decodes the synthetic GLB using **our own parser**, deforms the indexed vertices using our first-party CPU LBS, renders 18 frames through our native WebGL2 triangle shader, checks positive vertex motion and **no Three/React module network requests**. Diagnostic screenshot/JSON only.
- `.github/workflows/first_party_strict_glb2_source_gate.yml`: runs zero-dependency Node tests first, then the real headless browser pipeline. Existing main editor, Work CT and Blender model branches are untouched.

## Boundaries remaining before final Three.js removal

Original-v1 provenance, complete anatomically accepted canonical skeleton, full-body mesh, normal/tangent/UV/multi-material support, multiple meshes/skins, node hierarchy and bind transforms, GLB textures where appropriately created/licensed, compression decisions, CPU-to-GPU skinning optimization, model deformation correctives, animated skin physical realism, WebGL shadows/cameras/equipment/raycasting and broad exercise visual acceptance remain unresolved. The strict parser is intentionally designed **not to quietly fake support for those unsupported areas**.

**Neither skinned GLB geometry nor original human character is production approved.** A test fixture from project-created geometry is not a demonstration that all independently sourced model assets or 304 historical videos are first-party. PT-App itself retains zero npm runtime dependencies; `three` still exists in the separate original animation-studio editor via one isolated gateway during phased conversion. Anatomical skeleton readiness unchanged, **0 READY /9 PARTIAL /3 BLOCKED**, CP1 Gate6 not passed.
