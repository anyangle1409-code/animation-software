**12 October 2026; first-party Chat Lane G diagnostic only.** Stacked on verified [post-SHA source protection G4t PR #87](https://github.com/anyangle1409-code/animation-software/pull/87). This is an isolated imported function and optional DOM-control binding, **not** a new default app screen, deployed server, production animation or verified full-body screenshot.

## Purpose

Work's actual 17,946-vertex, 35,888-triangle ORIGINAL_v1 review body has 67 skin joints, six zero-rest sparse shoulder morph targets and source SHA-256 `d267dac344affb5d52c7155f8d0254794e818a8eab3ad54f7f263694f36c390d`. The real asset resides in owner's private ChatGPT Library and **must not** be uploaded as an anonymous demo or committed to Git. The existing first-party GLB importer G4r, source typed-array/palette guard G4t and actual GPU-rest bridge G4s already exist but there was no bounded **owner-local file** and camera selection interface. This adds the smallest integration seam while all Work anatomy/rights/movement acceptance gates remain independent.

## Added

`src/viewer/firstPartyOriginalFullBodyLocalReview.mjs` exports:

- `openOriginalFullBodyOwnerLocalReview({ownerFile,canvas,view,width,height,pixelRatio})`: accepts **only an owner-selected local File-like object** with the exact review-only filename and 1,495,720-byte size; locally loads bytes, independently checks full SHA/source rig/67 bones/zero morph weights through G4r, prepares an unforgeable G4s REST source handle, then invokes actual native WebGL2 after G4t rechecks every source buffer/pose palette. No web fetch, URL input, asset caching or imported third-party renderer. Fails explicitly when WebGL2 is unavailable (no fake CPU mannequin/success).
- `cameraForOriginalFullBodyReview(view)`: returns five fixed bounded glTF Y-up camera settings for `front`, `rear`, `left`, `right`, `three-quarter` with common target Y=0.91m and equal camera distance. The names remain visual review labels, not a medically accepted landmark registration.
- `bindOriginalFullBodyOwnerLocalControls({fileInput,canvas,cameraSelector,statusTarget})`: **optional** UI wiring for a future locally hosted owner-only review page; no page or library action is auto-started and no unapproved PT exercise is substituted. Disposing releases the WebGL2 renderer/session.

**Hard guarantees:** exact original SHA; no anatomical pose/morph progression or unverified foot-length update; user-supplied file only; no external media requests; no PT App `.webm/.mp4` library modification; source buffer and graphics rest-palette mutation blocked by G4t. The viewer output marks `productionReady:false`, `fullBodyLiveExerciseApproved:false`, `anatomicalMotionApproved:false`, `originalRightsForReleaseApproved:false`.
